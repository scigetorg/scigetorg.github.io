## Asides

Asides (also called callouts) draw attention to a piece of information.

<Aside>A default note aside. No type specified.</Aside>
<Aside type="tip" title="Custom title">Useful for "pro tips" — explicit title here.</Aside>
<Aside type="caution">Warning-level callout. Use for things users might trip on.</Aside>
<Aside type="danger">Strongest callout. Use for destructive actions or security issues.</Aside>

```mdx
<Aside>A default note aside.</Aside>
<Aside type="tip" title="Custom title">Useful for "pro tips".</Aside>
<Aside type="caution">Warning-level callout.</Aside>
<Aside type="danger">Strongest callout.</Aside>
```

Markdown directive syntax also works:

:::note
A note written with the `:::note` directive.
:::

:::tip[Custom title]
Tip with custom title via directive.
:::

:::caution
Caution.
:::

:::danger
Danger.
:::

````md
:::note
A note written with the `:::note` directive.
:::

:::tip[Custom title]
Tip with custom title.
:::
````

## Tabs

Toggle between related content blocks. The `syncKey` prop keeps tabs in sync across the page.

	<TabItem label="Linux" icon="linux">Install via `apt` or `rpm`.</TabItem>
	<TabItem label="macOS" icon="apple">Install via the `.dmg` or `brew`.</TabItem>
	<TabItem label="Windows" icon="seti:windows">Install via the `.exe`.</TabItem>
</Tabs>

```mdx
<Tabs syncKey="os">

	<TabItem label="macOS" icon="apple">Install via the .dmg or brew.</TabItem>
```

## Code blocks

Standard fenced markdown with syntax highlighting, titles, line markers, and diff highlighting.

```bash title="install.sh"
# Install the Sciget App on Ubuntu
sudo apt install -f ./ScigetApp-Setup-Debian.deb
scigetapp --version
```

```ts {2,4-5} title="example.ts"
function greet(name: string) {
	const message = `Hello, ${name}`;
	console.log(message);
	const upper = message.toUpperCase();
	return upper;
}
```

```diff lang="ts"
function greet(name: string) {
-	console.log(`Hi, ${name}`);
+	console.log(`Hello, ${name}!`);
}
```

````md
```bash title="install.sh"
sudo apt install -f ./ScigetApp.deb
```

```ts {2,4-5} title="example.ts"
const message = "highlighted line";
```

```diff lang="ts"
-	old line
+	new line
```
````

## Icons

Starlight bundles a large icon set. Use `<Icon>` for inline icons, or pass an
`icon` prop to Card / LinkButton / TabItem.

<Icon name="rocket" size="2rem" /> <Icon name="heart" size="2rem" color="var(--sl-color-accent)" /> <Icon name="github" size="2rem" /> <Icon name="external" size="2rem" /> <Icon name="approve-check" size="2rem" /> <Icon name="warning" size="2rem" />

```mdx
<Icon name="rocket" size="2rem" />
<Icon name="heart" color="var(--sl-color-accent)" />
```

Browse the full icon catalogue: [starlight.astro.build/reference/icons](https://starlight.astro.build/reference/icons/).

## Hero config

Used on the home page (`template: splash`). Configured via frontmatter:

```yaml
hero:
  tagline: Your tagline here.
  image:
    file: ../../assets/sciget-icon.svg
  actions:
    - text: Primary action
      link: /get-started/
      icon: right-arrow
      variant: primary
    - text: Secondary action
      link: /about/
      variant: minimal
```
